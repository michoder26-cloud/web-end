# ติดตั้ง web-end ทีละขั้น (ภาษาไทย)

ฟรีทั้งหมด ไม่มีค่ารายเดือน ใช้บัญชีของคุณเอง 3 บัญชี: [Cloudflare](https://dash.cloudflare.com/sign-up), [GitHub](https://github.com/signup) และ [Claude](https://claude.ai) (Claude ใช้หรือไม่ใช้ก็ได้)

ใช้เวลาประมาณ 5–10 นาที ปุ่มและหน้าจอของ Cloudflare กับ GitHub อาจเปลี่ยนชื่อเล็กน้อย ให้มองหาปุ่มที่มีความหมายใกล้เคียง

## 1. กดปุ่มติดตั้ง

1. เปิด [หน้า web-end](https://github.com/michoder26-cloud/web-end) แล้วกดปุ่ม **Deploy to Cloudflare**
2. ถ้ายังไม่ได้ลงชื่อเข้าใช้ Cloudflare ให้ลงชื่อเข้าใช้หรือสมัครก่อน
3. Cloudflare จะขอเชื่อมกับ GitHub ให้กดเชื่อม เมื่อ GitHub ถามว่าให้เข้าถึง repository ไหน ให้เลือก **Only select repositories** เพื่อไม่ให้แตะโปรเจกต์อื่นของคุณ
4. ตั้งชื่อเว็บ (เช่น `baan-coffee`) ใช้ตัวอักษรภาษาอังกฤษตัวเล็ก ตัวเลข และขีด `-` เท่านั้น ช่องอื่นปล่อยไว้ตามที่ Cloudflare ใส่ให้
5. กดปุ่มสร้างหรือ Deploy แล้วรอ 2–5 นาที
6. **ถ้าหลุดไปหน้าอื่น** (เช่น หน้าแรกของ GitHub หรือ Cloudflare) ให้กลับมากดปุ่ม Deploy to Cloudflare อีกครั้ง Cloudflare จะจำสิ่งที่ทำไปแล้ว

## 2. เปิดเว็บของคุณ

1. เมื่อ Cloudflare ทำเสร็จ จะเห็นที่อยู่เว็บที่ลงท้ายด้วย **`.workers.dev`** เช่น `baan-coffee.ชื่อคุณ.workers.dev`
2. กดที่อยู่นั้น หรือปุ่ม **Visit**
3. ถ้าหาไม่เจอ: เข้า Cloudflare แล้วเปิด **Workers & Pages** กดชื่อเว็บของคุณ แล้วมองหาที่อยู่ที่ลงท้ายด้วย `.workers.dev`

## 3. เริ่มสร้างเว็บ

1. ในหน้าเว็บใหม่ กด **เริ่มสร้างฟรี** คนแรกที่กดจะได้เป็นเจ้าของเว็บ จึงควรกดทันทีหลังติดตั้ง
2. เลือกทางเดียวก็พอ:
   - **เริ่มจากตัวอย่าง** กดเลือกแบบที่ใกล้กับธุรกิจคุณ (ร้านกาแฟ ร้านค้าออนไลน์ คลาสและการจอง บริการ หรือผลงาน) ได้เว็บตัวอย่างทันที
   - **สร้างกับ Claude** ทำตาม 3 ขั้นบนหน้าจอ: คัดลอกลิงก์ เปิด Claude แล้ววางลิงก์ใน Add custom connector แล้วส่งข้อความแรก

## 4. สร้างบัญชีเข้าใช้ (สำคัญ ทำครั้งเดียว)

ตอนแรก ที่อยู่ของหน้าหลังบ้านเป็นกุญแจเดียวที่เข้าได้ หลังบ้านจะขึ้นกล่อง **สร้างบัญชีเข้าใช้** ไว้ให้

1. ใส่ชื่อ อีเมล และรหัสผ่าน (อย่างน้อย 8 ตัวอักษร) แล้วกด **สร้างบัญชีเจ้าของ** ไม่ต้องวางลิงก์อะไร
2. ต่อจากนี้ เปิด `ที่อยู่เว็บของคุณ/admin` แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่านนี้ ได้จากทุกเครื่อง
3. ถ้าจะเชื่อม Claude ทีหลัง ไปที่ `/admin` ในหัวข้อ Claude แล้วกด **สร้างลิงก์ Claude ของฉัน**

## 5. เผยแพร่

เมื่อพอใจแล้ว กด **เผยแพร่** ที่มุมขวาบนของหลังบ้าน หลังจากนั้นการแก้ไขจะยังไม่แสดงต่อคนทั่วไปจนกว่าจะกดเผยแพร่อีกครั้ง

## อัปเดตอัตโนมัติ

เว็บที่ติดตั้งตั้งแต่เวอร์ชัน 0.20 จะอัปเดตเองวันละครั้งเมื่อมีเวอร์ชันใหม่ ไม่ต้องทำอะไร เว็บที่ติดตั้งก่อนหน้านั้น ให้เปิดหน้า **อัปเดต** ในหลังบ้าน (อยู่ในเมนู เพิ่มเติม) แล้วทำตามที่บอก กดปุ่มเดียวแล้วกด Commit changes

## ถ้าติดปัญหา

- **เปิดเว็บแล้วขึ้นหน้าว่างหรือ error** รอ 2–3 นาทีแล้วรีเฟรช Cloudflare อาจยังสร้างไม่เสร็จ
- **ลืมรหัสผ่าน** เปิด `/admin/recover` แล้วใช้ลิงก์ลับของเจ้าของ (ลิงก์หลังบ้านที่ขึ้นตอนเริ่ม)
- **ส่งอีเมลจากเว็บ** ต้องมีโดเมนของตัวเองและบัญชี Resend ถ้ายังไม่มีโดเมน ใช้การแจ้งเตือนผ่าน Telegram หรือ Discord ฟรีที่หน้า **เชื่อมต่อ** แทน
